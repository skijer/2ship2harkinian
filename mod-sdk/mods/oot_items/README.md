# OoT Items in MM

Separate behavior mod using OoT Asset Loader. Six items appear in Give/Remove and default to Items page 3. Registered items require human Link.

- Fairy Slingshot: press its assigned button to aim, press again to fire; A/B/C-Up leaves aiming. Uses native MM slingshot projectiles, 50 stored seeds; reacquiring refills them.
- Boomerang: throws a returning projectile that stuns with native Zora boomerang damage. Press again to recall it; wall/hit/timeout also starts its return.
- Megaton Hammer: uses MM's two-handed melee animations and an OoT hammer model. Strikes carry Goron punch/pound damage, rather than importing OoT's player action or MM-incompatible hammer switches.
- Din's Fire: expanding flame blast, native fire-arrow collision damage, 12 MP.
- Farore's Wind: set a point on solid ground, then cast again to return; hold R when casting to dispel. Stores entrance, room, position and yaw per save; return uses MM's respawn transition and waives its void damage. 6 MP.
- Nayru's Love: protective aura for 1,200 game ticks (one minute at normal MM speed), 24 MP; ends on scene change.

Compiled and linked in Release. These are native MM adaptations; gameplay and the 3D equipment preview still require in-game validation.
