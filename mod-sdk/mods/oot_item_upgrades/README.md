# OoT Item Upgrades para MM

- Martillo de `oot_items` → Hacha Gerudo: arma custom, lanzamiento y destrucción de rocas plateadas mediante las rutinas y drops de MM.
- Kokiri → Razor → Gilded: progresión nativa de espada de MM.
- Master Sword de `oot_equipment` → Real Master Sword: proyectiles con la salud completa.
- Giant’s Knife → Biggoron → Great Fairy’s Sword: cuchillo custom con ocho impactos de duración, espada custom y arma nativa de MM con recuperación de vida/magia.
- Hookshot → Longshot → Ultrashot: una única casilla nativa; alcance doble en el segundo nivel y cuádruple en el tercero, con mayor velocidad en el tercero.

Las entregas progresivas están disponibles en el Save Editor. Las simulaciones del randomizer no alteran la propiedad del equipo real. Se requieren `oot_items`, `oot_equipment` y los assets de OoT actualizados.

Compilación y enlace verificados. El usuario realiza las pruebas ingame.
